# Local alert policy

**Owner: Abubakar Ahmed.** Implement local alert policy for unknown, uncertain or face-unclear zone-entry events. Persist the selected event and any necessary local evidence, apply a per-track/event cooldown, and provide a clear alert record for the Streamlit dashboard to display. Known staff entries should be logged without an intruder alert. This module does not send Telegram messages or use another external alert service.
